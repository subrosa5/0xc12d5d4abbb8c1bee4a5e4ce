# 0xc12d5d4abbb8c1bee4a5e4ce

Локальный файловый сейф с пороговым восстановлением и воспроизводимыми испытаниями после сбоев.

Название похоже на ключ, но это просто название.

**Статус: концепция и документация. Рабочей реализации пока нет.**

## Как это будет работать

1. Создать случайный ключ и зашифровать файл.
2. Разделить ключ на доли, например по схеме «любые 3 из 5».
3. Передать доли доверенным участникам.
4. Восстановить ключ и файл при наличии достаточного числа долей.

## Три части проекта

- **Сейф:** шифрование файлов и восстановление доступа.
- **Лаборатория сбоев:** проверка прерванной записи, повреждений и восстановления состояния на тестовых данных.
- **Упаковка ошибки:** минимальный воспроизводимый сценарий для разработчика.

В первой версии ключ восстанавливается на устройстве получателя. Получатель может сохранить ключ и расшифрованные данные. Сбор долей не обеспечивает обязательное новое согласие участников при каждом открытии.

Проверки сбоев не доказывают абсолютную безопасность. Для надёжного обнаружения подмены всего сейфа старой корректной версией нужен независимый источник информации о последней версии.

Постквантовая передача долей и подтверждения с нескольких устройств рассматриваются для следующих этапов. Первая цель — описать формат, модель угроз и сделать небольшой проверяемый CLI-прототип.
