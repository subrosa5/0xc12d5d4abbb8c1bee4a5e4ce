# 0xc12d5d4abbb8c1bee4a5e4ce

**Зашифруй файл. Распредели доли. Проверь восстановление.**

Команда — `x12`. Название репозитория похоже на ключ, но это просто название.

Рабочий экспериментальный CLI v0.1.0. Внешнего аудита ещё не было; для знакомства используйте тестовые данные.

## Запуск

Нужны Python 3.11+ и uv. Первые целевые платформы — macOS и Linux.

```sh
git clone https://github.com/subrosa5/0xc12d5d4abbb8c1bee4a5e4ce.git
cd 0xc12d5d4abbb8c1bee4a5e4ce
uv sync --locked
uv run x12 lab --report ./lab-report
```

Лаборатория создаёт только синтетические данные. Она проверяет восстановление всеми десятью комбинациями «3 из 5», неверный пароль, недостаточные/повторные/чужие/повреждённые доли, повреждение контейнера, параллельное шифрование, восстановление копии и принудительное завершение процесса перед публикацией файла.

```sh
uv run x12 replay ./lab-report/report.json --out ./replayed-lab
```

Данные примера повторяются, но ключи и шифротексты генерируются заново. Отчёт не содержит ключей или пользовательских файлов. Сокращение ошибки nonce показано на отдельной намеренно неправильной модели счётчика, не на найденном дефекте сейфа.

## Создать сейф

```sh
uv run x12 create ./document.txt --out ./my-vault --threshold 3 --shares 5
```

Программа запросит пароль защиты долей длиной от 12 байт UTF-8. Для файла создаётся случайный AES-256-ключ. Две его половины независимо разделяются библиотечной схемой Шамира. Доли защищены AES-GCM с ключами из общего пароля через scrypt, с отдельными солями и nonce.

В новой папке появятся `vault.x12`, пять файлов `share-*.x12share` и отметка `COMPLETE`. Передайте доли разным участникам и отдельно сохраните пароль. Хранение всех долей вместе лишает распределение смысла. Потерянный пароль нельзя восстановить из долей.

## Восстановить

```sh
uv run x12 recover ./my-vault/vault.x12 \
  --share ./my-vault/share-001.x12share \
  --share ./my-vault/share-003.x12share \
  --share ./my-vault/share-005.x12share \
  --out ./restored.txt
```

Нужны любые три корректные доли и пароль. Подлинность проверяется до записи открытого файла. Существующие файлы не перезаписываются. Для автоматизации доступен `--password-file /путь/к/локальному/файлу`; завершающий перевод строки удаляется.

`uv run x12 inspect ./my-vault/vault.x12` показывает открытые метаданные без проверки подлинности.

## Ограничения

- До 64 МиБ на файл; обработка целиком в памяти.
- Ключ восстанавливается на устройстве получателя; его и открытые данные можно сохранить.
- Размер и параметры порога открыты, исходное имя файла не записывается.
- Старые контейнеры и доли остаются действительными. Обнаружение полной подмены истории требует независимого источника свежести.
- Пароль общий для долей; их защита не является подписью участника.
- При обрыве создания может остаться неполная папка. Исходный файл не удаляется. `COMPLETE` записывается последним.
- После аварии возможны временные файлы `.x12-*`; при восстановлении они содержат уже аутентифицированные открытые данные. Гарантированного стирания секретов из памяти Python нет.
