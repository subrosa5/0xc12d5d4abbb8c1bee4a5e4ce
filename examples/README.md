# Synthetic lab example

`lab-report/` is an actual v0.2 report generated by `x12 lab` with public fixture seed 12. It contains no vaults, keys, shares, passwords or user files. `v0.1-lab-report/` preserves the original report and requires the old tool version for replay.

From the repository root, replay it into a new directory:

```sh
uv run x12 replay examples/lab-report/report.json --out /tmp/x12-example-replay
```

Keys and ciphertext are freshly generated; only the synthetic fixture and experiment definitions are repeatable. The nonce-counter failure is a separate intentionally broken demonstration model, not a reported defect in the vault.

For reduction against the actual streaming engine:

```sh
uv run x12 reduce examples/failure-trace.json --out /tmp/x12-minimal-error
uv run x12 replay-trace /tmp/x12-minimal-error/trace.json
```

This produces an actual authentication error after a synthetic footer modification. Correct rejection of modified data is expected behavior, not a discovered vulnerability.
